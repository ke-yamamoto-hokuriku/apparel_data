# アパレル生産国チェック 2021–2026

北陸大学「グローバル・ガバナンス」の履修者が、自分の持っている服のタグを見て入力したデータである（2021〜2026年度、5,444件）。

- ダッシュボード：https://ke-yamamoto-hokuriku.github.io/apparel_data/
- データ：[apparel_data_2021_2026.csv](apparel_data_2021_2026.csv)（UTF-8、BOM付き。Excel・Tableau・Exploratoryで開ける）

## 列の説明

| 列 | 内容 |
|---|---|
| 年度 | 調査を行った年度 |
| 種類 | 服の種類（Tシャツ／その他トップス／アウター／パンツ／その他ボトムズ／靴／小物・下着・その他） |
| 新品/古着 | 新品／古着／不明・もらいもの |
| 購入年 | 服を買った年。2021・2022年度の調査には設問がないため空欄 |
| ブランド | 表記のゆれを一つの名前に統一したブランド名。わからないものは「不明」 |
| ブランド本拠地 | 件数の多いブランドのみ記入 |
| 生産国 | 洗濯タグに書かれた生産国。わからないものは「不明」 |
| 地域 | 生産国の地域区分 |

## 注意

- 氏名・メールアドレスなど個人を特定できる情報は含まれていない。行の順番も年度内で入れ替えてある。
- 履修者の持ち物を集めたデータであり、日本全体の傾向を示す統計ではない。
